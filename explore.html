Career Explorer

Technical Orientation

Day-to-Day: Provision, configure, and monitor cloud infrastructure; troubleshoot outages; automate deployments; support releases and production systems.

Skills: AWS, Azure, or GCP; Terraform/CloudFormation; Docker, Kubernetes; Linux, networking, Python/Bash.

Entry-Level Expectations: Explain VMs, containers, subnets, IAM roles, and DNS; deploy a basic cloud app or automated deployment with Terraform.

Strong Candidates: Have hands-on lab or personal-project experience with a cloud provider (not just certifications), understand core networking and Linux fundamentals, and can explain the trade-offs behind a design choice, not just name the tool used.

Salary: ~$134k median (computer network architect benchmark)

Growth: Junior Cloud Engineer → Cloud/Platform Engineer, DevOps/SRE → Cloud Architect

Day-to-Day: Monitor security alerts, suspicious logins, and phishing reports; investigate incidents to determine real threats vs. false positives; review vulnerabilities and coordinate patching; assist with access reviews, incident-response plans, and audits; communicate findings to technical and nontechnical audiences.

Skills: Networking fundamentals (TCP/IP, DNS, HTTP/S, VPNs, firewalls); Windows/Linux fundamentals; SIEM tools (Splunk, Microsoft Sentinel, QRadar); endpoint tools (Defender for Endpoint, CrowdStrike, SentinelOne); vulnerability scanners (Nessus, Qualys, Rapid7); Wireshark, Nmap, Python, PowerShell, Bash.

Entry-Level Expectations: Explain common threats (phishing, ransomware, credential theft, social engineering); understand authentication vs. authorization and least privilege; read basic Windows/Linux logs and recognize suspicious behavior; write a clear incident summary. CompTIA Security+ can help.

Strong Candidates: Show genuine curiosity about how attacks work, have foundational networking and OS knowledge, and can walk through a structured, calm thought process for investigating and escalating an incident rather than jumping straight to conclusions.

Salary: $129.18k median (information security analysts); range roughly $75k-$199.85k+

Growth: IT Support/Networking → SOC/Security Analyst → Security Engineer, Incident Responder, Cloud Security Specialist, Threat Hunter → Security Manager or CISO

Day-to-Day: Install, configure, and maintain database systems; manage users, permissions, backups, and recovery; monitor performance and support developers with schema and query issues.

Skills: SQL, relational database design, indexing; PostgreSQL, SQL Server, Oracle, MySQL/MariaDB; backup/recovery, replication.

Entry-Level Expectations: Write SQL with joins/filters/aggregates; understand keys, normalization, and transactions; perform a basic backup and restore.

Strong Candidates: Are comfortable with SQL well beyond the basics, show methodical attention to detail around backups and permissions, and can explain the reasoning behind a normalization or indexing decision, not just recite the definition.

Salary: $104.6k median (DBA); $139.5k median (database architect)

Growth: Junior DBA/Data Ops Analyst → DBA → Senior DBA/Database Engineer → Database Architect

Day-to-Day: Configure, maintain, secure, and troubleshoot switches, routers, firewalls, wireless networks, and VPNs; monitor performance and manage IP addressing/DNS/DHCP.

Skills: TCP/IP, subnetting, VLANs, DNS/DHCP; Cisco, Juniper, Aruba, Fortinet, Palo Alto; Wireshark, scripting.

Entry-Level Expectations: Explain IP addressing, routers, switches, firewalls, VLANs, and VPNs; use ping, traceroute, and Wireshark; Network+ or CCNA helps.

Strong Candidates: Can explain fundamentals like subnetting and the OSI model clearly and simply, have some hands-on lab or homelab experience, and communicate technical issues to non-technical coworkers without losing patience.

Salary: $99.1k median

Growth: Help Desk/Network Technician → Network Administrator → Network Engineer, Cloud Network Specialist, or Network Architect

Day-to-Day: Review requirements, create and run test cases, record and retest bugs, perform regression testing, and improve quality alongside developers and product teams.

Skills: Test planning, defect reporting, regression testing; Jira, TestRail, Postman; Selenium, Cypress, Playwright; Java/JS/Python/C# for automation.

Entry-Level Expectations: Write a clear, reproducible bug report; create test cases from a requirement; explain severity vs. priority; basic API and SQL testing.

Strong Candidates: Are meticulous and skeptical by nature, think from the end user's perspective to find edge cases others overlook, and can disagree with a developer about a bug professionally, backed by clear evidence.

Salary: $104.3k median

Growth: Manual QA Tester → QA Analyst → Test Automation Engineer/SDET → QA Lead, Test Architect, or Quality Manager

Day-to-Day: Turn feature requests and user needs into working software; write, test, debug, review, and maintain code; build websites, mobile apps, APIs, databases, integrations, and internal tools; participate in planning meetings, code reviews, demos, and bug triage.

Skills: Java, Python, JavaScript/TypeScript, C#, C++, Kotlin, or Swift; SQL, relational databases, APIs, JSON, debugging, automated testing; Git/GitHub, Jira, Docker, CI/CD, cloud platforms; front-end (React, Angular, Vue) and back-end (.NET, Spring, Django/Flask, Node.js) frameworks.

Entry-Level Expectations: Build a small complete application, not just individual assignments; use Git branches, commits, and pull requests; write SQL with joins and aggregations; build or consume a basic API; debug errors systematically; write basic tests.

Strong Candidates: Have a portfolio of real, self-directed projects rather than only class assignments, debug independently instead of guessing, and can explain the reasoning behind their code, not just produce something that runs.

Salary: $135.98k median

Growth: Junior Developer → Developer → Senior Developer → Technical Lead, Staff Engineer, Software Architect, or Engineering Manager

Day-to-Day: Research user needs, create user flows and wireframes, build prototypes, test designs with users, and collaborate with developers and product managers.

Skills: Figma, FigJam, Adobe XD; wireframing, prototyping, information architecture, accessibility (WCAG); basic HTML/CSS/JS.

Entry-Level Expectations: A portfolio with case studies covering research, design decisions, and outcomes; Figma proficiency; understanding of responsive/accessible design.

Strong Candidates: Have a portfolio with clear case studies showing problem, process, and outcome; can justify design decisions with user evidence rather than personal taste; and can point to a time they actually tested a design with real users.

Salary: $104k median (web/digital interface designers)

Growth: Junior UX/UI Designer → UX/Product Designer → Senior Designer → UX Lead, Principal Designer, or Design Manager

Business Orientation

Day-to-Day: Analyze business, sales, marketing, or operations data; define KPIs and build dashboards; investigate changes and recommend actions to stakeholders.

Skills: Excel, SQL, Power BI/Tableau/Looker; often Python or R; KPI design, business metrics, statistics, and storytelling.

Entry-Level Expectations: Translate a broad business problem into metrics; build a clear dashboard or report; use spreadsheets and SQL confidently.

Strong Candidates: Can turn a vague business question into measurable metrics on their own, explain findings in plain business language rather than jargon, and back up a recommendation with a clear line of reasoning from the data.

Salary: Varies by title; $120.2k median as an analytics-family benchmark (data scientist)

Growth: Business/Operations Analyst → Senior Analyst → Analytics Manager, Product Analytics, Strategy, or Data Science

Day-to-Day: Gather data from spreadsheets, databases, CRM/ERP systems, and web analytics; clean, validate, and query data; build reports and dashboards; identify trends, risks, and opportunities; present findings to nontechnical stakeholders.

Skills: Excel/Google Sheets (pivot tables, lookups); SQL (joins, aggregations, CTEs); Power BI, Tableau, Looker, Qlik; Python/pandas or R; basic statistics and data storytelling.

Entry-Level Expectations: Clean a messy spreadsheet and explain the fix; write SQL with joins, filters, and groupings; build a dashboard that answers a specific business question; understand correlation vs. causation; explain common business metrics.

Strong Candidates: Are comfortable and fast in SQL and spreadsheets, show healthy skepticism toward messy or inconsistent data before trusting it, and can tell a clear, evidence-backed story rather than just handing over a chart.

Salary: No single BLS figure covers every "data analyst" role; the broader data-scientist median of $120.23k is a useful upper-family benchmark

Growth: Reporting Analyst → Data Analyst → Senior/BI Analyst → Analytics Engineer, Product Analyst, Data Scientist, or Analytics Manager

Day-to-Day: Interview users and map business processes (order-to-cash, procure-to-pay, payroll, inventory); gather requirements and recommend improved workflows; configure ERP modules or coordinate custom changes; support data migration and go-live.

Skills: Business-process mapping, requirements gathering, data migration/validation; Excel, SQL, APIs, Jira, Visio, Lucidchart; ERP platforms (SAP, Oracle, Microsoft Dynamics 365, Workday, NetSuite).

Entry-Level Expectations: Understand why integrated ERP data matters; use Excel well and write introductory SQL; create a process flowchart or basic requirements document; understand a basic process like procure-to-pay.

Strong Candidates: Take time to understand a business process deeply before recommending a change, ask sharp clarifying questions, and can bridge technical configuration details with the real operational impact on the people using the system.

Salary: $105.85k median (computer systems analyst benchmark)

Growth: ERP/Business Systems Analyst → Functional Consultant → Senior Consultant → Solution Architect, Implementation Manager, or Practice Lead

Day-to-Day: Interview stakeholders and document business needs; define workflows, requirements, user stories, and acceptance criteria; support testing and adoption.

Skills: Requirements elicitation, process modeling, SQL; Jira, Azure DevOps, Confluence, Visio; Agile fundamentals.

Entry-Level Expectations: Write a basic user story with acceptance criteria; create a process map; use Excel and introductory SQL.

Strong Candidates: Listen carefully to what stakeholders actually need (not just what they say), write requirements that are clear and testable, and can navigate competing priorities without losing anyone's trust.

Salary: $105.9k median (computer systems analyst benchmark)

Growth: Junior BA → Business Analyst → Senior BA/Systems Analyst/Product Owner → Manager, Consultant, or Solution Architect

Day-to-Day: Understand client technology or process problems, analyze systems and costs, develop recommendations, and support implementation and training.

Skills: Excel, PowerPoint, SQL, Jira/ServiceNow; requirements gathering, process mapping, vendor evaluation, change management.

Entry-Level Expectations: Strong communication and presentation skills; ability to organize an unfamiliar problem into a clear recommendation; Excel proficiency.

Strong Candidates: Communicate confidently with people at any level, structure an ambiguous problem quickly instead of freezing up, and can adapt a technical explanation to whoever they're talking to.

Salary: $101.9k median (management analyst benchmark)

Growth: Analyst/Associate Consultant → Consultant → Senior Consultant → Manager, Principal, or Partner

Day-to-Day: Research a client's industry and operations, analyze data and interview stakeholders, build models and executive presentations, and support implementation.

Skills: Excel, PowerPoint, data analysis, financial analysis, process mapping, and presentation skills; SQL/BI tools helpful.

Entry-Level Expectations: Strong analytical writing and quantitative reasoning; ability to structure a complex problem and present a logical conclusion.

Strong Candidates: Show sharp quantitative reasoning under time pressure, structure a messy, open-ended problem into something logical, and can defend a recommendation persuasively without getting defensive when challenged.

Salary: $101.9k median

Growth: Analyst → Consultant → Senior Consultant → Manager, Principal, Partner, or Strategy Executive

Day-to-Day: Coordinate multiple related projects supporting a larger goal; manage cross-project dependencies, budgets, and risks; provide executive updates and governance.

Skills: Program governance, portfolio planning, budgeting, risk and dependency management; Jira, MS Project, Excel, executive reporting.

Entry-Level Expectations: Generally not an entry-level role — build coordination skills first through project coordinator, analyst, or PM roles.

Strong Candidates: Track many moving pieces without losing sight of the bigger picture, surface risk to leadership early rather than after it becomes a crisis, and keep multiple teams aligned toward a shared goal.

Salary: $102.3k+ baseline (often higher with broader scope)

Growth: Coordinator/Analyst → Project Manager → Senior PM → Program Manager → Portfolio Leader, PMO Director, or Executive

Day-to-Day: Define scope, schedule, budget, and deliverables; run status meetings; coordinate teams and vendors; track risks, issues, and deadlines.

Skills: Project planning, risk management, stakeholder communication; Jira, MS Project, Smartsheet, Asana; Agile and waterfall concepts.

Entry-Level Expectations: Build a simple project plan with milestones and risks; understand Agile basics; write clear status updates. Project coordinator is a common entry point.

Strong Candidates: Keep a team organized and on schedule without micromanaging, communicate proactively about risk instead of waiting to be asked, and stay calm and fair when resolving conflict between stakeholders.

Salary: $102.3k median

Growth: Project Coordinator → Project Manager → Senior PM → Program Manager, PMO Leader, or Director

Day-to-Day: Meet with users to understand needs and workflows; analyze systems and integrations; define requirements; create diagrams and test plans; support implementation and training.

Skills: Requirements analysis, process mapping, SQL, databases, APIs; Jira, Visio, Lucidchart, ServiceNow.

Entry-Level Expectations: Create a process map, use case, or requirements document; understand relational databases and introductory SQL.

Strong Candidates: Move comfortably between technical and business perspectives, document clearly enough that others can follow without them in the room, and can justify a methodology choice like Agile vs. Waterfall for a given project's context.

Salary: $105.9k median

Growth: Junior Systems Analyst → Systems Analyst → Senior Analyst → Solution Architect, ERP Consultant, or IT Manager

Data Sources

Salary figures are U.S. median annual wages from the Bureau of Labor Statistics' Occupational Employment and Wage Statistics (BLS OEWS) program, bls.gov/oes. Where a career doesn't map to a single BLS category, we used the closest matching occupation as a benchmark (noted in parentheses next to each figure). Day-to-day duties, skills, and entry-level expectations were compiled from current job postings and industry role descriptions for each career.
